## rules/ の読み込み

### 何が起きていたか

グローバル CLAUDE.md は、`rules/claude-behavior-guidelines.md` と `rules/fable-engineering-judgment.md` を「Opus / Sonnet のときだけ読み込み、それ以外のモデルは読まない」と定めていた。しかし、`~/.claude/rules/*.md` はモデルに関係なく全セッションで自動的に読み込まれる（公式ドキュメント。ヘッドレスの haiku セッションでも両ファイルの見出しを確認できた）。2 ファイルで約 29KB ある。

### 判断

- 採用案: ファイルは `rules/` に残し、CLAUDE.md と両ファイルの冒頭の記述を「全セッションで自動的に読み込まれる」に書き換える
- 却下案: 自動読み込みされない場所に移して、条件付き読み込みを成立させる。Haiku / Fable での読み込みは減らせるが、メインで使う Opus でも「指示に従って自分から Read したときだけ」になり、読み込みの保証を失う。移動の操作も、auto モードで自己改変として拒否された

pull スキルの同期対象の表と、プロジェクト CLAUDE.md のリポジトリ構造にある `rules/` の説明も、同じ理由で直した。
